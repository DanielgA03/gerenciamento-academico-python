# Sistema de Gerenciamento Acadêmico (SGA-Python)

O **Sistema de Gerenciamento Acadêmico** é uma aplicação de terminal em Python voltada para o armazenamento seguro, processamento dinâmico e consolidação de rendimento de estudantes. O projeto aplica conceitos essenciais de estruturas de dados e os princípios da **modularidade** e **responsabilidade única (SRP)** para garantir um código limpo, testável e de fácil manutenção.

## 🚀 Funcionalidades

- **Armazenamento Seguro:** Organização de dados na memória através de uma estrutura flexível de lista de dicionários.
- **Motor de Lógica Independente:** Funções puras e isoladas para o cálculo de médias aritméticas e validação de regras institucionais de aprovação.
- **Relatório Consolidado:** Geração de tabelas formatadas diretamente no terminal, exibindo o status de todos os alunos em bloco.
- **Robustez contra Falhas:** Tratamento preventivo para listas vazias, evitando erros fatais como a divisão por zero.

---

## 📋 Pré-requisitos

Para executar a aplicação ou rodar os testes, você precisará apenas do ambiente básico do Python instalado em sua máquina:

- **Python 3.8** ou superior.
- Nenhuma biblioteca externa é necessária (o sistema utiliza exclusivamente módulos nativos).
